2. **Mimari test paketi:** NetArchTest.Rules (son sürüm 2021-05) bakım şartını karşılamadığından ADR-0003 ile `TngTech.ArchUnitNET` seçildi (Apache-2.0, son sürüm 2026-08, İnsan onayı: Nilay Cezik, 2026-10-21). Çekirdek paket yeterli; xUnit adaptörü eklenmez.
3. **Paketler (insan onayı gerekli, tümü test projelerinde; Web için ek paket yok):** `xunit.v3`, `xunit.runner.visualstudio`, `Microsoft.NET.Test.Sdk` (test çatısı, MIT/Apache); `TngTech.ArchUnitNET` 0.13.4 (Apache-2.0; mimari test; ADR-0003 — NetArchTest.Rules yerine); `Microsoft.AspNetCore.Mvc.Testing` (MIT; AC-6/7 HTTP kanıtı); `bunit` **eklenmez** — gerek yok. Sürümler build'de resolve edilip sabitlenir; floating yok.
4. **Hard-coded UI metni yok (R-4):** otomatik tarama testi yazmıyorum (kapsam genişlemesi); `.razor` dosyalarında literal yok, review'da kontrol edilir.
5. **`dotnet format` build sunucusu bırakabilir** (check.conf'ta `--disable-build-servers` yok): residue ölçümü gösterir; sızarsa format satırına bayrak eklenir (check.conf zaten bu plan kapsamında).
